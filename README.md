# Pong

Un Pong en HTML/JavaScript, codé en vibecoding. On peut jouer seul contre une IA ou à deux.

## Jouer

En ligne : https://romzer-png.github.io/pong/ (ou ouvre `index.html` dans ton navigateur).

- Menu : `1` pour jouer contre l'IA, `2` pour jouer à deux
- Contre l'IA : `Z` / `S` ou `↑` / `↓`
- À deux : joueur 1 avec `Z` / `S`, joueur 2 avec `↑` / `↓`
- `Espace` : pause, ou rejouer quand la partie est finie
- `Échap` : retour au menu
- Le premier à 7 points gagne
